# ابزارهای محلی

شش اسکریپت در `tools/` مانده است؛ بقیهٔ اسکریپت‌های موقتیِ مراحل طراحی حذف شدند.
همه با `node` اجرا می‌شوند و به یک سرور در حال اجرا نیاز دارند
(`npm run build && node .next/standalone/server.js` یا `npm run dev`).

| ابزار                 | کار                                                                                                                                        | نمونهٔ اجرا                                                   |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| `qa-audit.mjs`        | ممیزی دسترس‌پذیری و کیفیت: خطای کنسول، کنتراست واقعی (نمونه‌گیری پیکسلی)، حلقهٔ فوکوس، هدف لمسی، لینک مرده، متادیتا، ساختار سرتیترها، سرریز | `AUDIT_URL=http://127.0.0.1:3000/ node tools/qa-audit.mjs`   |
| `check-fallbacks.mjs` | تضمین اینکه با `prefers-reduced-motion: reduce` و با جاوااسکریپت خاموش هیچ محتوایی نامرئی نمی‌ماند                                         | `BASE=http://127.0.0.1:3000/ node tools/check-fallbacks.mjs` |
| `theme-shots.mjs`     | سرریز افقی در ۷ عرض + تصویر «بالای صفحه» و «پایان صفحه» در هر دو تم                                                                        | `BASE=http://127.0.0.1:3000/ node tools/theme-shots.mjs`     |
| `scroll-shots.mjs`    | قدم‌زدن کامل صفحه و عکس‌برداری قاب‌به‌قاب (برای مرور بصری)                                                                                 | `BASE=http://127.0.0.1:3000/ node tools/scroll-shots.mjs`    |
| `make-og.mjs`         | ساخت `public/og.png` (۱۲۰۰×۶۳۰) با فونت و موزاییک درون‌خطی                                                                                 | `node tools/make-og.mjs`                                     |
| `mock-api.mjs`        | شبیه‌ساز سبکِ API برای کار بدون بک‌اند                                                                                                      | `node tools/mock-api.mjs`                                    |

## قاعده‌ها

- تصویرها در `~/shots/` نوشته می‌شوند (بیرون از مخزن، در `.gitignore` هم هست).
  ریشهٔ پروژه و ریشهٔ ورک‌اسپیس تمیز می‌ماند.
- هیچ ابزاری مقدار پیش‌فرضِ پورت ندارد که با پورت‌های پیش‌نمایش قاطی شود؛
  `BASE` / `AUDIT_URL` را صریح بدهید (پیش‌فرض `http://127.0.0.1:3000/`).
- این‌ها ابزار توسعه‌اند: در `eslint` نادیده گرفته می‌شوند ولی `prettier --check`
  شاملشان می‌شود، پس قبل از کامیت `npm run format` را بزنید.
