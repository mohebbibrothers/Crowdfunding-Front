# صفحهٔ فهرست حرکت‌ها (`/campaigns`)

## قرارداد آدرس

همهٔ وضعیت صفحه در آدرس است — قابل اشتراک، بوکمارک و بازگشت با دکمهٔ مرورگر.
هیچ فیلتری در state محلی ذخیره نمی‌شود (جز متنِ در حال تایپ در کادر جست‌وجو).

| پارامتر    | مقادیر                                                           | پیش‌فرض  | نگاشت به بک‌اند     |
| ---------- | ---------------------------------------------------------------- | -------- | ------------------- |
| `q`        | متن آزاد (۸۰ کاراکتر، پاک‌سازی‌شده)                              | —        | `q`                 |
| `category` | نامک دسته (`health-care`)                                        | —        | `category`          |
| `province` | یکی از ۳۱ استان                                                  | —        | `province`          |
| `urgency`  | `normal` \| `urgent` \| `emergency`                              | —        | `urgency`           |
| `status`   | `active` \| `executing` \| `completed` \| `fulfilled`            | `active` | `status`            |
| `order`    | `fair` \| `newest` \| `ending_soon` \| `most_funded` \| `urgent` | `fair`   | `order`             |
| `matching` | `1`                                                              | —        | `has_matching=true` |

مقادیر پیش‌فرض از آدرس حذف می‌شوند (`toQueryString`)، پس آدرس تمیز می‌ماند.
هر مقدار ناشناخته بی‌صدا حذف می‌شود و صفحه نمی‌شکند (`parseFilters`).

## وضعیت‌ها

| حالت       | چه چیزی دیده می‌شود                                                 |
| ---------- | ------------------------------------------------------------------- |
| عادی       | سرصفحه + آمار + نوار ابزار + شبکهٔ کارت‌ها                           |
| صافی فعال  | چیپ‌های قابل حذف بالای شبکه + شمارش زنده                            |
| نتیجهٔ خالی | پنل «چیزی پیدا نشد» با دلیلِ وابسته به صافی + دکمهٔ بازگشت            |
| خطای API   | پنل «ارتباط برقرار نشد» + تلاش دوباره (صفحه ۵۰۰ نمی‌دهد)            |
| بارگذاری   | `app/campaigns/loading.tsx` هم‌شکل شبکهٔ نهایی                       |
| موبایل     | نوار ابزار دو ردیفه + شیت صافی‌ها (`<dialog>` بومی، Esc و backdrop) |

## تصمیم‌های فنی

- **بدون صفحه‌بندی سرور:** بک‌اند پارامتر صفحه ندارد و سقف ۱۰۰ مورد برمی‌گرداند.
  پس همهٔ کارت‌ها در HTML سرور رندر می‌شوند (سئو و بدون‌جاوااسکریپت کامل) و
  `ShowMore` فقط _نمایش_ را پله‌ای می‌کند (۹ + ۹). هیچ درخواست اضافه‌ای نمی‌رود.
- **`generateMetadata`:** برای صفحهٔ صافی‌دار `robots: noindex` می‌دهد تا نسخه‌های
  تکراری ایندکس نشوند؛ canonical همیشه `/campaigns` است.
- **صفحه پویاست (`ƒ`)** چون `searchParams` دارد، ولی فراخوانی API با
  `revalidate: 60` کش می‌شود؛ هر بازدید به بک‌اند نمی‌خورد.
- **`matching` فقط وقتی نمایش داده می‌شود که** پرچم `feature.matching_grants`
  در `v1/meta` روشن باشد.

## هم‌راستایی قرارداد (باگ‌هایی که در این مرحله رفع شد)

| فیلد        | فرانت (قبل)                                                | بک‌اند (واقعی)                                                |
| ----------- | ---------------------------------------------------------- | ------------------------------------------------------------- |
| `status`    | `draft·active·funded·completed·cancelled·expired·archived` | `draft·active·paused·completed·executing·fulfilled·cancelled` |
| `urgency`   | `normal·important·emergency·critical`                      | `normal·urgent·emergency`                                     |
| `order`     | `fair·newest·ending·progress·urgency`                      | `fair·newest·ending_soon·most_funded·urgent`                  |
| `page_size` | فرستاده می‌شد                                              | وجود ندارد                                                    |

اثر باگ: `.catch()` در zod وضعیت `executing` را به `active` و فوریت `urgent` را به
`normal` تبدیل می‌کرد — یعنی برچسب کارت‌ها بی‌صدا غلط می‌شد.
